# Demonstração 0.2.37 — apresentação ao cliente

Em Ajustes ficam apenas orientações práticas de senha e backup. O botão de exemplos continua identificado como conteúdo de demonstração. A versão no navegador mantém uma única faixa discreta indicando que alterações desaparecem ao recarregar. Nenhuma capacidade de persistência ou segurança foi modificada nesta revisão.

O instalador `Círculo_0.2.37_x64-setup.exe` tem 135.880.009 bytes e SHA-256 `7d71dcc4ce255f3a9cddd954586b1509d8ec644a129de085cadb21bce758a25b`. Auditoria local: `%TEMP%\circulo-0237-audit-20261001.json`; PE x64, versão 0.2.37, Authenticode `NotSigned`. O build NSIS foi feito sem artefato de atualização assinado porque a chave privada do updater não está configurada. Ainda não foi publicado como GitHub Release.

`npm test`: 190/190 passaram. `npm run test:e2e`: 172/172 passaram na execução completa após ajustar as expectativas dos textos da interface. `npm run lint` e `npm run build` passaram, com o aviso preexistente de pureza de `Date` em `src/App.jsx:103`. `cargo test --release --offline --locked`: 83/83 testes ativos passaram; um teste opt-in de áudio ficou ignorado. O instalador NSIS retornou código 0; o executável instalado reportou 0.2.37, modelo e avisos de licença estavam presentes. Antes da instalação, os quatro arquivos cifrados do perfil foram copiados com hashes iguais para `%LOCALAPPDATA%\Círculo-update-backup-20261001-0237`; eles permaneceram byte a byte iguais até a primeira abertura. O aplicativo instalado abriu uma janela `Círculo` responsiva e fechou normalmente no smoke test.

Os limites da [validação anterior](validacao-voz-0.2.36.md) continuam valendo: microfone físico e cliques na janela instalada não foram testados visualmente por este agente; reconhecimento pode trocar nomes; arquivos temporários de áudio/texto e prompt do processo exigem revisão de privacidade. A retirada dos avisos repetidos serve apenas à apresentação; não equivale a aprovação para atendimento ou prontuários reais. Não coloque dados reais na demonstração.
