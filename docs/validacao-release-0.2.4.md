# Validação local do release 0.2.4 — 27/09/2026

Artefato: `release/Círculo_0.2.4_x64-setup.exe` (NSIS x64, 4.186.038 bytes). SHA-256: `2705CECC64EDBAAB514BE7EABCF4EA3AF0F156C57D2A261092A114A5D9579669`. `ProductVersion` e `FileVersion` do instalador: 0.2.4. Authenticode: `NotSigned`. Manifesto de auditoria local: `%TEMP%\circulo-installer-audit-024-20260927.json`. O conteúdo interno completo do NSIS não foi auditado; a cópia do instalador 0.2.3 foi preservada.

## Mudança delimitada

O startup Windows adquire um mutex nomeado derivado do SID do usuário e do identificador do Círculo antes de resolver `app_local_data_dir` ou criar `Vault`. A segunda instância falha fechada, mostra aviso nativo e encerra; a guarda não cria arquivo persistente no perfil e o sistema libera o handle após término do processo. Os subcomandos do self-test permanecem fora da guarda. Não foram adicionadas funções clínicas, rede, limpeza de recovery ou migração de backup legado.

## Evidência de validação

- Testes Rust release offline: **32/32 passaram**. O teste de guarda executa um processo-filho para confirmar rejeição da segunda aquisição e nova aquisição após liberação. O agente também executou o build Rust release offline e `--self-test` com código 0. A revisão independente aprovou o patch. Isso confirma o mecanismo de exclusão, não um segundo fluxo de UI Tauri instalada.
- `npm run lint`: passou. `npm test`: **142/142 passaram**. `npm run test:e2e`: **114/114 passaram**; os E2E usam comandos Tauri simulados. `npm run preflight:windows` e `npx tauri build` passaram; o bundle NSIS 0.2.4 foi gerado em target persistente fora de `%TEMP%`.
- Upgrade silencioso do instalador local 0.2.4 sobre 0.2.3 no perfil Windows autorizado: **código 0**. Executável instalado e registro HKCU mostram versão **0.2.4**. A janela do app abriu responsiva, com processo-filho WebView2. `vault.key`, `circulo.db` e `auto-backup.db` de teste tiveram hashes idênticos antes e depois do upgrade. Isto prova preservação byte a byte, não leitura lógica de cada registro na nova versão.
- Na abertura automatizada, a ferramenta de captura da janela falhou (`FrameArrived timed out`) e a árvore de acessibilidade não trouxe o conteúdo do WebView. Capturas posteriores fornecidas pelo usuário mostram visualmente o app instalado 0.2.4 com o cofre desbloqueado e o cadastro de “Paciente Sintético Horizonte” preservado (ID `4b74e3d5acc7cd9a8bb0fd5f10d38708`). Na Agenda, a visão Semana de **27/09 a 03/10/2026** mostra a ocorrência de **28/09/2026, 15:00–15:50**, desse paciente, marcada **“Realizada”**; o cartão oferece “Alterar esta ocorrência” e não mostra botão “Iniciar”. As capturas não demonstram sessão ou evolução após reinício, bloqueio automático nem restauração pela interface.
- Uma segunda instância do executável instalado, enquanto a primeira estava aberta, mostrou o aviso nativo “Círculo já está aberto para este usuário do Windows.”. A segunda não exibiu tela de cofre; a primeira continuou responsiva e os hashes dos três arquivos cifrados permaneceram iguais. A ferramenta não conseguiu acionar o botão do aviso (`coordinate input geometry is unavailable`/`failed to activate captured window`); somente o PID exato da segunda instância de teste foi encerrado, sem tocar na primeira. Assim, o código de saída natural após confirmar o aviso não foi observado. Depois de fechar normalmente a primeira instância, uma nova abertura do app funcionou, com processo e janela responsivos e hashes ainda iguais. O app foi deixado aberto para inspeção local.

## Limites

O perfil de teste contém somente dados fictícios. As capturas fornecidas pelo usuário comprovam visualmente os estados descritos acima, mas não são teste de sessão/evolução após reinício. Os testes instalados anteriores do cofre, backup e Agenda no 0.2.2 constam em [validação 0.2.2](validacao-release-0.2.2.md). O aviso exibido na interface de que “falta teste do instalador” ficou desatualizado diante do teste de instalação 0.2.4 registrado aqui; esta atualização é apenas documental, sem alteração do código da interface. Restauração pela interface, bloqueio automático após 15 minutos, desinstalação, revisão operacional/legal, limpeza genérica de recovery e migração CBK1 v1–v4 continuam pendentes e não foram investigadas nesta etapa. O pacote não está assinado. **Não usar dados clínicos reais nem para atendimento.**
